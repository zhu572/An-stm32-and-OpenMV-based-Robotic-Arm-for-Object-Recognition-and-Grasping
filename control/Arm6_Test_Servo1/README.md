# Arm6_Test_ServoAll —— 六路舵机固定角度测试

**一句话**：上电后 **S1–S6 六个通道同时输出同一个固定角度（默认 90.0°）**，用来一次性验证六个舵机的接线、供电和方向是否正确。

原名 `Arm6_Test_Servo1`（当时只驱动 S1），现在扩展到六路；目录名保留不变，工程名/输出名也不变，避免你重新找文件。

## 一、编译与烧录

Keil 打开 `Arm6_Test_Servo1.uvprojx` → **Rebuild** → 烧 `Objects\Arm6_Test_Servo1.hex`。

厂商代码（CMSIS / 启动文件 / system）来自官方包
`C:\Users\zhu\STM32Cube\Repository\STM32Cube_FW_F1_V1.8.7`，与 `Arm6_Unified` 相同。

## 二、接线

| 舵机 | STM32 | 定时器通道 |
|---|---|---|
| S1 | **PA0** | TIM2_CH1 |
| S2 | **PA1** | TIM2_CH2 |
| S3 | **PA2** | TIM2_CH3 |
| S4 | **PA3** | TIM2_CH4 |
| S5 | **PA6** | TIM3_CH1 |
| S6 | **PA7** | TIM3_CH2 |

- 六个舵机的**信号线**分别接上表引脚
- 舵机**电源用外部 5 V**，不要从开发板 3.3 V 或 GPIO 取电
- 舵机电源 GND、开发板 GND **必须共地**
- 六路同时动作的峰值电流要够（空载测试可以只接一路电源，但要保证共地）

## 三、上电现象

1. **六个舵机同时转到 90°** 并稳住（有负载时会保持力矩）
2. 之后不再变化，也不再理串口

> ⚠ 上电瞬间六个舵机会**同时**跳到中位。如果机械臂装好了，请先确认这个动作不会让连杆互相碰撞，或者先卸下舵盘。

## 四、可调参数（`Core/Src/main.c` 顶部）

| 宏 | 默认 | 说明 |
|---|---|---|
| `FIXED_ANGLE_X10` | `900` | 固定角度，单位 **0.1°**：`900`=90.0°，`0`=0°，`1800`=180° |
| `SERVO_STATIC_ONLY` | `1` | `1`=恒定输出固定角度（当前）；`0`=改成「每收到一帧视觉数据，六路一起翻 ±9°」 |
| `TOGGLE_LOW_X10` / `TOGGLE_HIGH_X10` | 900 / 990 | 仅 `SERVO_STATIC_ONLY=0` 时使用 |

脉宽映射：`0.0° → 1000 µs`，`180.0° → 2000 µs`，所以 90.0° = 1500 µs，与正式固件一致。

个别舵机装上后方向相反、或中位不对，这里先不用管——**本工程只验证"能不能动、动得对不对"**，方向/零位标定在正式固件的 `g_servo_config` / `g_joint_map` 里做。

## 五、结果判读

| 现象 | 含义 | 处理 |
|---|---|---|
| 六路都稳在 90° | ✅ 六路 PWM + 电源全部正常 | 可以回去调 `Arm6_Unified` |
| 某些路不动、其余正常 | 该路信号线接错 / 舵机坏 / 该路电源没接 | 交换两根信号线验证，或换舵机试 |
| 全部不动、舵机没力 | 没有 PWM 或没有舵机电源 | 万用表量 PA0 对 GND 应约 **0.375 V**；量舵机电源是否 5 V |
| 全部不动但舵机发热/抖动 | 脉宽超出舵机规格或电源压降 | 先断开负载，改用 90° 空载测试，检查供电电流 |
| 动一下就复位 | 电源电流不足 | 换更大电流的 5 V 电源，加去耦，先单路测试 |

## 六、测完记得烧回主固件

本工程没有任何串口命令（没有 `$PING/$ON/$AUTO/$KIN`）。验证完请重新烧
`control\Arm6_Unified\Objects\Arm6_Unified.hex`，那才是带视觉闭环的正式固件。
