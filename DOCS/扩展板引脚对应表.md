## 0. 板载固定电路

| 电路 | 连接 | 状态 | 影响 |
|---|---|---|---|
| Type-C + USB-TTL（CH340，COM6） | **PA9(USART1_TX) / PA10(USART1_RX)** | 📷✅ | 电脑串口 + ISP 下载；此二脚被固化占用 |
| DC-DC 降压 **MP1584EN**（3A） | 12V → 5V | 📷 | 5V 电源来源；丝印 `MP1584EN` / `S778678` / `MPS39` |

🧠 推论：PA9/PA10 未引出到排针，是被板载 CH340 占用；因此 **USART1 不能重映射**（会断 Type-C）。

## 1. 板载接口一览（排针之外）

| 接口 | 针脚 | 数量 | 已知 | 状态 |
|---|---|---|---|---|
| 总线舵机口 | 5V / GND / S | **6 个，S 全部并联** | **S 由 USART3_TX (PB10) 驱动**（实测：舵机接 S 可动）；S 经 1 kΩ 上拉到 5V | ✅ |
| 手柄口 | 2×3（6 针） | 1 | 用途待定 | 📷 |
| 同步口 | K1 / RX / TX / G / 5V | 1 | **K1 = PA8**（实测导通）；**RX = B11 (PB11)、TX = B10 (PB10)**，与蓝牙接口同一路 USART3（经串联电阻） | 📝 |
| **蓝牙接口** | **TX / RX / G / 5V** | 1 | **蓝牙接口 RX = B11 (PB11)，蓝牙接口 TX = B10 (PB10)** | 📝 |

> **蓝牙接口**一行不可省略 —— 它把 USART3 的两个脚引成了独立排针口。
> 也就是说：**蓝牙接口 TX = PB10、蓝牙接口 RX = PB11**，与传感器侧第 16 格 B10、第 15 格 B11 是同一对脚。
>
> **同步口**的 RX/TX 接的也是这一路（同样经串联电阻）。所以 **USART3 一共扇出到 3 个物理出口**：
> 传感器侧 B10/B11 排针、蓝牙接口、同步接口 —— 三者是同一个网络，**不能同时挂两台设备**。

| USART1 | PA9 / PA10 | Type-C：电脑 / ISP | 📷✅ |

## 6. 总线口 S 针：已结案 ✅

**实测结论（2026-11-01）**：烧 `ServoTest.hex`（USART3 / PB10 发众灵指令）后，把舵机信号线分别接到
**蓝牙接口 TX**、**同步口 TX**、**总线口 S** —— 三处**舵机都能动**。

> 即：**总线口 S 就是 USART3_TX（PB10）的驱动出口**，中间经串联电阻/保护元件。

之前的所有电阻实测（S 空闲 5V、S↔5V = 986Ω 即 1 kΩ 上拉、S↔各排针 ≥10 kΩ/20 MΩ、
40 脚翻转时 S 不动）**全部是"隔着有源器件 + 仪表判读"造成的假象**，不能用来否定连接关系。
**以通电实测为准。**

### 因此

- **6 个总线口可以直接插舵机用**，不需要飞线。
- 6 个口 S 并联，全部由 USART3 一条总线驱动，靠 ID 0..5 寻址。

| 事实 | 数据 |
|---|---|
| S 空闲电压 | 5.0 V（1 kΩ 上拉） |
| S ↔ 5V | 986 Ω，正反一致（真电阻） |
| 驱动脚 | **PB10 = USART3_TX**（实测：三处出口均可驱动舵机） |

**反向对照（2026-11-01）**：同一舵机测试逻辑改由 **USART2 / PA2** 发送（`ServoOnPA2.hex`），
舵机仍接总线口 S → **完全不动**。正反两面都成立，驱动脚唯一确定为 **PB10**。

## 7. 实际接线与串口分配

### 舵机（无需飞线）

```
舵机信号线 ──▶ 任一总线口的 S 针（6 个口等价，S 全并联）
舵机电源 ──▶ 外部 5~12 V
GND      ──▶ 板上 GND（必须共地）
```

固件：`ServoTest.hex`（`ServoTest/ServoTest.c`）—— 按 ID 0..5 逐台点名，
每台 LED 闪 N+1 下后摆动 ±30°，用来核对 ID ↔ 关节。

### ID ↔ 关节（2026-11-01 实测确认 ✅）

| 舵机 ID | 关节 | 部位 |
|---|---|---|
| **0** | 关节 1 | 底座 |
| **1** | 关节 2 | 大臂 |
| **2** | 关节 3 | 小臂 |
| **3** | 关节 4 | 腕俯仰 |
| **4** | 关节 5 | 腕回转 |
| **5** | 关节 6 | 夹爪 |

> **连号，无偏移**：`servo_id = joint - 1`。与 10-29 记录的"整体错开一位"一致，
> 但当时 ID 0 未确认，现已补齐。

### 三路串口的最终分工

| 外设 | 引脚 | 用途 | 备注 |
|---|---|---|---|
| USART1 | PA9 / PA10（Type-C） | 电脑 / ISP | 板上固化 |
| **USART3** | **PB10 / PB11** | **舵机总线**（含蓝牙接口、同步口、B10/B11 排针） | 三出口同一网络 |
| USART2 | PA2 / PA3（排针 A2/A3） | **OpenMV 视觉** | 需两根杜邦线；OpenMV 是 3.3V，不存在超压问题 |

> OpenMV 不能用蓝牙口/同步口 —— 它们和舵机是同一条 USART3。
